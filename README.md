# Paradise Nursery Shopping Application

This project is a React and Redux based shopping cart application for an online plant store called Paradise Nursery.

## Features

- Landing page with background image
- About Us section
- Product listing page
- Shopping cart functionality
- Add to cart
- Increase and decrease quantity
- Remove items from cart
- Dynamic cart count
- Redux state management

## Technologies Used

- React
- Redux Toolkit
- React Redux
- Vite
- CSS

## Run Project

npm install

npm run dev
